How to read the confidence score

90 or above means the resource is unattached and old enough to look abandoned. 70 to 89 means likely safe but still worth a quick owner check. 50 to 69 means the signal is real but recent or ambiguous. Below 50 means it likely belongs to DR or shared infrastructure and should not be terminated without deeper validation.
Confidence is a conservative termination heuristic, not an automatic delete recommendation. The agent never runs these commands. Each delete command is for an operator to review and run.

Method and limits

Spend narrows where to look; savings and confidence decide what to act on first. Termination candidates are scored by a conservative confidence to terminate heuristic based on association state, age, and naming. Where Azure Monitor metrics or Activity Logs could not be read, the score relies on those heuristics only and the resource is treated more cautiously.
This report is read only. It proposes changes and provides operator ready delete commands, but the agent runs none of them.
