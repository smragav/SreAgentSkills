The three lines that land
  • Nothing here writes. Every skill runs with Reader. The agent proposes the command, a human runs it. That is why security teams let it near production.
  • The reports are one file. Inline CSS, CSS bar charts, no CDN, no images. Mail it, attach it to a change record, open it on a plane. It looks the same.
  • The findings pay for themselves. The cost skill found $27,450 a month. The reliability skill found the Critical single instance. One funds the other, in the same session.
Questions you will get, and the answer
Is the data real?These are rendered samples on a synthetic Contoso estate, so the numbers are stable for a demo. The skills read live Azure Resource Graph, Azure Monitor, Activity Log, Resource Health, and the service control planes. Point the agent at a subscription and the same reports come back with your resources.
What if the agent cannot read something?It records the resource as not assessed rather than failing the run. Coverage equals the read scope. A few skills touch data planes that need their own read role, such as Key Vault item metadata and Microsoft Graph for application credentials, and a denied read is reported, never assumed.
Can it fix things?By design, no. It ranks the finding, shows the evidence, and hands you a copyable command. The change stays in your change process.
How does severity get decided?Severity reflects blast radius and likelihood, not effort. A single instance virtual machine carrying checkout is Critical even though the fix is easy. Findings that infer a cause carry a separate confidence band, so a guess never reads like a fact.
How do we run it on a schedule?Most skills ship an optional scheduled sweep and an optional custom agent alongside the skill. Deploy with the shared script, or paste the skill into the Builder by hand.
Method and limits
  • Read only throughout. Skills propose recommendations and operator ready commands. A human reviews and runs anything that changes or deletes a resource.
  • Default Reader scope. Coverage equals the agent's read scope. A skill may ask for temporary access when a read is denied, but it never assigns roles itself.
  • Evidence first. Every finding carries its evidence and a severity or a confidence. Severity reflects blast radius and likelihood, not effort.
  • Counts are per report and per scope. Different skills scan different resource sets, for example 312 monitorable resources against 214 taggable ones, so do not add totals across reports.
  • The sample reports are a synthetic Contoso estate, generated on 2026-07-09 and 2026-07-10, so a demo stays stable. Timestamps inside the reports are the generation time, not today.
